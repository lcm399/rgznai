# 电子信息实验仿真 AI 助手

iCAN 2026 AI 应用创新挑战赛 · 软件赛道参赛作品（电子信息工程专业方向）。

面向电子信息工程专业同学的实验/仿真教学智能体：用自然语言描述电路、实验数据
或问题，AI 负责**分析电路、生成仿真代码、解读波形数据、专业答疑**。

## 一、快速开始

```bash
# 1. 安装依赖（建议用虚拟环境）
python -m venv .venv
# Windows: .venv\Scripts\activate     Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt

# 2. 配置大模型 Key（三选一：DeepSeek / Qwen / GLM）
copy .env.example .env      # Windows；Mac/Linux 用 cp .env.example .env
# 编辑 .env，填入你的 LLM_API_KEY

# 3. 启动
streamlit run app.py
```

> 不配置 Key 也能运行：电路计算、Bode 图、FFT 频谱、代码生成等**确定性功能
> 完全离线可用**，只有「AI 讲解/答疑/对话」需要 Key。

## 四、核心设计（评审亮点 / 八大创新点）

1. **AI 理解与确定性计算分层**：数值全部由 numpy/scipy 解析公式算出，LLM 只负责
   理解与讲解；AI 解释与计算结果冲突时以计算为准，杜绝"大模型瞎算电路"。
2. **多工具 Agent 协同（Function Calling）**：AI 自主完成「接收请求→分析决策→
   调用工具→反馈结果」闭环，而非页面写死的问答。
3. **工程单位自然语言解析**：`1kΩ`、`1μF`、`10mH` 等带单位参数直接解析为 SI 单位，
   大小写敏感（m=毫 vs M=兆），贴近真实实验输入。
4. **工程计算交叉验证**：关键物理量（如 RLC 带宽 BW=f0/Q 与 BW=R/(2πL)）用两条独立
   公式互查，不一致自动警示，体现工程严谨性。
5. **RAG 工程知识增强**：教材/实验手册片段检索、带来源回答，零外部依赖、可离线。
6. **自动生成实验图形**：Bode 图、暂态曲线、频谱图随确定性结果自动生成，中文字体适配。
7. **实验可记录、可复现、可信度显式**：一键复制参数重跑；本地 JSON/Markdown 记录与
   报告；✓⚠️❌ 可信度等级，拒绝"准确率 99%"式虚报。
8. **从"问答"升级为"实验闭环"**：7 阶段实验状态机（准备→参数→理论→计算→图形→
   验证→结论）把"做实验"变成可追踪、可定位、可恢复的闭环。
